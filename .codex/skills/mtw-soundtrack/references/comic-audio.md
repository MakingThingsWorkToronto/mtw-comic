## New asset reference contract

For new character clips and cached previews, prefer `canonicalPath: "wiki/soundtrack-library/assets/voices/<character>/<version>.mp3"` and an exact declared `sha256`. A root-relative canonical path in existing `path`/`previewAsset` also works; the narrow `../soundtrack-library/assets/...` form supports existing comic consumers. `receiptCanonicalPath` points to `wiki/soundtrack-library/records/...json`. Old `assets/...` and `records/...` entries retain their comics-library interpretation solely for compatibility. Absolute paths, traversal, backslashes, unsupported media and missing recording hashes fail intake.

New room metadata uses `canonicalPath`, `originalCanonicalPath`, optional `originalSha256`, `receiptCanonicalPath`, `normalizationReceipt`, `encodedMeasurementReceipt` and `monoReceipt` pointing into soundtrack assets/records. Comic-specific sounds.json may retain scene lookup/direction while linking these canonical media records. Preserve original and normalized variants and exact encoded measurements; do not reuse fixed legacy receipt defaults for a new take. Refresh through the maintained producer, not hand edits to generated comic-audio projections.

## Installed regression and live legacy links

Run `node .codex/skills/mtw-soundtrack/scripts/comic-audio-regression.mjs` (or the paired Claude path) with no arguments after import. It resolves the repo from the installed script, derives expected counts from current canonical inputs, and saves its fixtures/report to a named OS temporary directory printed in the result. `--out <external-directory>` retains that evidence elsewhere. External staged scripts need `--root <repo>`; `--packet <external-packet>` selects candidates and falls back to current installed files for unchanged helpers. Source/DOM/server-handler checks do not claim native playback, HTTP, file-URL or hearing clearance. An exact pre-import inverse is optional: pass `--baseline-index <saved-original-index>` and `--index-additions <saved-additions-json>`; ordinary installed checks require no staging backup.

The start-all launcher (`npm run all`) now starts only the website and Studio; it no longer runs Soundtrack or Images static servers, and the producer no longer takes `--media-origin`, `--launcher-receipt` or `--clear-media-origin`. Legacy comic audio and receipt links are served by Studio's compatibility routes above, so no media-origin override is recorded in the projection. The producer starts or stops no service.

## Recorded speech and mixed review intake

Optional `wiki/comics-library/speech.json` has `{schemaVersion:1,records:[]}` and owns comic associations for actual recorded dialogue/narration. Uncreated lines and failed provider attempts remain plans/receipts, not playable rows. Each recorded row carries id, type `speech-dialogue` or `speech-narration`, title, characterId, provider, voiceId, exact text, measured durationSeconds, canonicalPath, sha256 and receiptCanonicalPath; preserve model/settings/sourceRefs and optional originalCanonicalPath/originalSha256/normalizationReceipt. New files and receipts belong in the soundtrack library. The producer's `--speech-source` supports an exact staged association source.

Optional `wiki/soundtrack-library/audio-records.json` uses the same envelope for `sound-effect-recording` and `review-evidence`. An audio-only WebM mixed-playback capture has type `review-evidence`, mediaKind `audio-only-review`, exact canonical file hash, measured duration, a retained review receipt and productionApproved false. It is evidence of that recorded run, not a generated character take or hearing approval. WebM is accepted only for canonical soundtrack review records; legacy audio paths retain their original extension limits. `--records-source` binds staged metadata. Refresh build/check after canonical import; the maintained regression derives all current counts and checks these new types without fixed totals.

For a new effect or mixed-review item whose canonical media/receipt already exist, run `comic-audio.mjs register-audio --record <exact-record.json>` to append it to audio-records.json. It refuses a changed retained id and missing/hash-mismatched canonical files. `--root` and an explicit `--out <external-library-directory>` stage a registry candidate for the integrating writer. Speech association writes stay with the comics source owner. Registration does not rebuild or approve media; follow with additive build/check.

For bounded existing provider-preview metadata/download intake, use [provider previews](provider-previews.md) and `scripts/provider-preview-intake.mjs`. It plans offline by default, caches only declared existing public previews on explicit download, excludes current locks/rejected history and preserves versioned bytes, actual container/full decode, UTF-8 metadata, immutable receipts and unverified rights. It does not generate, approve or select character speech.

## Music and comic audio stay separate; approval and descriptions

`/m/soundtrack` lists music only (sources.json/manifest.json); `/m/soundtrack/comic` lists comic audio (comic-audio.json). Comic audio never enters sources.json. Studio intake registers an uncatalogued file at the assets root as music (`needs source`) and any file in a subfolder (voices/, speech/, sounds/ ...) in `comic-intake.json`, which the producer projects as `unsorted-recording` until a comic catalog lists that path (13 October 2026: 122 Home voice takes had leaked into the music list this way and were removed).

Every comic clip is approved unless Matt rejects it. His Approve/Reject clicks in Studio write `comic-audio-review.json` (`decisions[id] = {approval, at, by}`), rebuild comic-audio.json through this producer and append to decisions.jsonl; a failed rebuild restores the old decisions. Each record carries `approval` and `approvalDecided`. Every record also carries a plain-words `description` (an input's own description wins; otherwise the producer writes one from character, words, scene, room or effect), and Studio's search covers it. `--review-source` binds a staged decisions file.
