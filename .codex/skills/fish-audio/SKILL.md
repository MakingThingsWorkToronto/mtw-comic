## Provider metadata must keep its UTF-8 source

The Home Grant preview name was damaged when a temporary Python intake read UTF-8 JSON using Windows' default cp1252. Keep the original provider receipt immutable and make any correction a new versioned receipt with before/source/after hashes. Read and write every metadata/request/receipt JSON explicitly as UTF-8 (`Path.read_text(encoding='utf-8')`, `write_text(..., encoding='utf-8')`; Node `readFile(..., 'utf8')`). Never rely on console/default-codepage decoding or repair names by guessing punctuation.

Compare the parsed name, description, labels and exact script with the retained provider-source Unicode values through the actual producer, including JSON `\u` escapes. Valid UTF-8 bytes can preserve an earlier cp1252 mistake. Extend the existing offline provider/catalog escape check with a non-ASCII name and curly punctuation: correct raw UTF-8 and escaped JSON must yield the same code points; deliberate cp1252 corruption must fail source equality; malformed bytes and known mojibake must fail the maintained text check. Run `python .codex/skills/agent-handoff/scripts/check_utf8_text.py <exact-changed-files>` (paired Claude path equivalent) before handoff, then inspect the next actual record in MTW Studio (`/m/comics` or `/m/soundtrack`). A fixture or metadata correction is not a fresh native visual pass, listening approval, provider call or permission to read credits. No extra provider request is needed to test this defect.

For a human-chosen provider reference, use the [comics casting contract](../mtw-comic-story/references/console.md#chosen-reference-escape-check). Vocal POW/WOW effects use the same exact-word gate as dialogue; select their effect direction separately from the narrator, reuse suitable saved sounds first, and never substitute an unrelated saved narration as an effect.
