# MTW raster subject contracts

This is the maintained subject catalog for a future **explicitly requested**
raster alternative. It preserves the applicable composition, label and material
decisions originally written in Appendix A. It is not a queue, status report,
generation prompt, or permission to resume raster work. Current user instructions
and project policy take precedence. SVG Flat remains the selected public style.

## Reference roles and treatment scope

- A selected original supplies camera, framing, object counts, positions and
  meaningful routes. Source names below identify the exact original within the
  canonical `wiki/image-library/assets/originals/` collection, resolved through each diagram's manifest `references[]`; confirm
  its hash against retained lineage and inspect it before a future call.
- **Holographic / Part 2:** retain the selected composition and permitted short
  internal labels reconciled with the corresponding SVG; remove only an overall
  image title. Keep required row, column and group headings. Do not import the
  photo-only omissions or substitutions below. For example, Why retains its
  knowledge/benefit labels and Capture / Organize / Apply / Review strip unless
  a separately recorded instruction overrides that scene.
- **Selected-reference photorealistic / Part 3:** apply the corresponding row
  below, including its explicit substitutions, removals and readable-label list.
  “As reference” means inspect and enumerate the actual short internal strings
  in the scene card; it does not authorize invented labels. Names on illustrative
  file pages may be made unreadable only where specified. Preserve required
  semantic internal headings while omitting the overall image title.
- **New-SVG counterpart / Part 2, either raster style:** the current native PNG
  supplies the complete composition; retain its canonical SVG and matching
  metadata hashes. A separately identified selected material image supplies
  appearance only. Read every object, label and route from the current SVG
  metadata; do not substitute an inspiration image's composition.
- Exact quantitative regions may use the limited additional geometry-reference
  procedure in [scene-brief](../../imagegen/references/scene-brief.md#quantitative-geometry-references).
  A selected source's inaccurate bar shape does not override authorized values.

## Shared photorealistic translation

Keep the same picture while removing glow, bloom, mesh/wireframe, tiny nodes,
see-through bodies and light filaments. People become real adults in modern
business clothing, retaining source poses; devices become brushed metal/glass;
documents become paper and card; servers become matte hardware; clouds and
tenant enclosures become frosted glass or smoked acrylic; locks become metal.
The brain is a nonglowing anatomical resin/glass model. Software panes become
clean floating screens without stands, invented readable UI text or extra marks.
Connections become thin teal cables/rails with the intended arrowheads.

Use a flat `#0b1419` background or actual transparency, soft local studio shading,
teal rim light and paper highlights. No room, floor, desk, horizon, haze, vignette
or scenery. Product marks are monochrome contours in paper or aqua, never their
original colors. Required labels use readable screen-aligned paper sans-serif.
Denied routes are red dashed lines stopping at a solid X before the boundary;
they never continue beyond the stop. Classification tags are not error statuses.
Retain the actual PNG dimensions; the current diagram brief requests landscape
16:9 and at least 1672 × 941. A retained shortfall is still a failed minimum check.

## Canonical input preservation

Original references, canonical SVGs and technology marks are read-only inputs.
This catalog preserves instructions, not those binary files. A future cleanup
must retain required originals and actual historical prompts/input/output hashes;
do not silently replace a missing composition with another generated treatment.
If an exact required input is unavailable, report that missing input before a call.

The compiler defaults to `wiki/image-library/manifest.json`. A selected source
must resolve through the diagram's original-reference records; a new-SVG source
and its metadata resolve from the chosen `svg-flat` or `svg-outline` treatment.
Declared source/SVG/metadata hashes are checked. The native PNG composition
reference is retained with new evidence under `records/` and tied to that SVG.
New briefs work only from canonical inputs. The retired `--legacy-discussion`
option rejects with migration guidance before reading source files. Historical
cards remain unchanged in the records archive; adapting a copy into a new
canonical brief is a new operation, never a replay claim for an old call.

Keep historical calls tied to the prompts, input roles and dependency revisions
actually used; missing historical revision/timing data remains unrecorded. A new
request reads these subject constraints and the current shared scene compiler;
it does not rewrite earlier provenance. Review remains the existing lighter
raster profile, with full SVG verification unchanged.
