# Style provenance: nothing invented

Matt, 2026-09-28: "add an anti-invention de-slop to the skill. we somehow want to ensure what is created is not invented vs the style we look for. our goal needs to be to lock this in."

`assets/style-provenance.json` is the whole allowed vocabulary. Matt’s 2026-10-09 exception requires branded teal `#1a9ba1` for all comic borders, gutters, inset bands and margins. Earlier white/printed-paper separator samples remain historical provenance, never current separator authorization. Balloon fills retain their own measured colours. Each visual element (balloon and caption kinds, lettering, colours, geometry, layouts, art treatments) cites where it comes from: a reference page and a crop box in its source pixels, plus the measurement behind it (the reference analysis, the balloon-shape analysis, Codex's reference descriptors, `sample-reference-paper.mjs`). A second list holds **Matt's exceptions**, each with the spec paragraph that authorizes it: the dark ground and the black-and-teal palette, translucent fills, the fear balloon, typed lettering, the ghost and box-by-box reveal, simple fades, wide pages, click-to-box, the looped song, the comic as the -b page's header, controls below the page.

The measured reference table, the ten recommendations, the per-file "what to take" guide, Codex's page descriptors and the ten anti-patterns are in [reference-measurements.md](reference-measurements.md).

**Nothing else is allowed.** Before adding anything visual, find it in the reference pages and add its citation, or get Matt's decision into the spec and add it as an exception. Then:

- The deslop lint fails any balloon kind or balloon field, CSS colour, `@font-face` family, `@keyframes` animation or story layout field that has no entry: `invented: <x>`.
- The Codex style check runs an **invention pass**: it lists every visual element in our render that does not appear in the reference pages and is not in the exceptions. The invention list must be empty. Matt’s 2026-10-04 style acceptance retired repeated numerical 95-style loops; inspect changed typography, balloons and geometry through the current checks instead.

Balloon, caption, voice and balloon-colour entries cite the measured crops of the balloon-shape analysis (`wiki/image-library/assets/experiments/comic-b/balloon-shapes/crops/ref-N.png`) and, as `box`, the same balloon located on its original page by template matching (the crops carry tracing overlays; Codex is shown the clean page boxes, `site/scripts/comic-story-style-refs.json`). Matt's exceptions added on 2026-09-29: the bead stem of the yellow thought balloon, the paper grain inside balloons, the lettering size floor, and the approved standard itself. Some other crop boxes are still approximate (see `_cropNote` in the JSON).

Matt, 2026-10-09 adds the bounded, art-only focus presets in [audio-motion](audio-motion.md). The provenance vocabulary records each preset separately. The deslop lint validates `panel.motion` against `still`, `push`, `drift-left`, `drift-right`, `shadow` and `light`, rejects unknown fields and non-finite or out-of-range beats/strength, and still rejects every CSS filter, blur, glow, overlay and whole-page effect. The regression exercises the actual validator with rejected unsafe fixtures; visual crop and device checks remain required.
