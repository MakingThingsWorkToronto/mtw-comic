## Write the scene before making planes

Answer the articulation questions in writing: what changes in this scene; what a first-time reader needs to see; and which one action or piece of evidence makes the change understandable. For every scene, freeze the source hash and record the following in the canonical storyboard:

| Requirement | Exact authored record |
|---|---|
| Story | Scene/panel IDs, place/time, actors, goal, causal action and exact written captions/balloons with ordinal and text hash |
| Layout | Desktop `r`, source `ar`, phone sheets/order, `phoneArt`/focus where needed, lettering areas and protected face/hand/evidence regions |
| Views and information | Reader/operator, material and actual readable face; required reading, content and reaction views, continuity and evidence hold |
| Layers | Back-to-front plane IDs/roles, canonical versions/hashes, matching canvas, alpha and required identity/colour state |
| Motion | Each affected panel/layer ID, implemented preset, beats/strength and why that plane should move; quiet layers explicit |
| Sound | Depicted panel room, meaningful event and delay, deliberate silence or selective low music, reused asset/hash |
| Dwell | Retimed start/end, each balloon reading interval, evidence visibility interval and any measured saved-speech duration/window |
| Standing | Authored, returned, inspected, registered, integrated, native/heard and human-approved states with exact evidence |

Keep the place/time caption distinct from job setup, identity and technical explanation. Do not turn a frozen ordinal into a new caption type without a semantic cold read. In the Home draft, a proposed rate/source line initially targeted the original 8:20 place caption; it passed ordinal checks but would have removed the clock. Retain that before/after finding with the storyboard, and recheck caption purpose alongside text hashes. Split an over-budget explanatory balloon into short complete statements and rerun the existing story/reading checks; do not shrink lettering. Moving a box between scenes also requires rechecking both scenes' phone sheets and gaps.

## Implemented plane contract

`scene.layers` is an ordered back-to-front array:

```ts
layers: [
  { id: 'room', src: '/comic/home/example-background-v1.png', role: 'background' },
  { id: 'people', src: '/comic/home/example-humans-v1.png', role: 'humans' },
  { id: 'digital', src: '/comic/home/example-agents-v1.png', role: 'agents', opacity: 0.97 },
  { id: 'evidence', src: '/comic/home/example-props-v1.png', role: 'props' }
]
```

These are schema examples, not existing asset references. Bind URLs only after the exact files exist. Each PNG/WebP is a complete full-page plane with the same aspect, coordinate system and panel geometry; use matching dimensions in production. URLs include extensions, unlike the extensionless `scene.art` derivative stem. The background is a clean plate; humans, agents and props have genuine alpha around their authored contents. An opaque rectangular foreground or a duplicated flattened page is not a separated plane. Preserve source masters, alpha and immutable prior versions. Register canonical artwork in `wiki/image-library/`; site files are checked integration copies. No new media authority belongs in an external packet or a worktree.

Separate solid humans from projected agents. Keep accepted silhouettes, costumes, colour states, faces and hands intact in the inked cartoon treatment. Source art must still identify the digital characters when motion is disabled. Put readable evidence on the physical front seen by its operator; treat phones, monitors, laptops and paper separately when their action or depth requires it. Do not use moving UI, edge effects or translucency to hide backwards geometry. Generated readable text is not a substitute for exact authored lettering.

`panel.layerMotion` addresses existing plane IDs:

```ts
layerMotion: [
  { layerId: 'room', preset: 'drift-left', beats: 4, strength: 0.25 },
  { layerId: 'digital', preset: 'projection', beats: 4, strength: 0.4 },
  { layerId: 'evidence', preset: 'still' }
]
```

Independent lifecycle floors use one genuinely separate full-canvas `light` plane per storey and `sprout: { floorIndex, floors, beats, activeFloors?, retainedFloors?, floorSource: { sceneId, panelId } }` (the actual motion object uses `preset: 'sprout'`). Indexes are one-based bottom-to-top, unique per panel and within the declared 2–16 storeys. All indexed motions in a panel share the same eligible/retained policy. The whole plane switches opacity 0→1 on its story-clock step with `clipPath: none`; it has no separate animation clock. Eligible retained floors remain lit on rewind/replay, while other floors resample the selected beat. Reduced motion reveals only eligible floors once the box starts; excluded future storeys remain dim/empty. A floor's source binds an existing authored scene/panel action; a future contribution can be declared only while that floor is excluded. This gate checks source lineage by IDs, not depicted content, exact image hashes or human word/image approval. At Home brain initialization, future skills/examples, produced drafts and authorization records remain excluded; later tested denial is not a completed or approved Send. Existing sprout without `floorIndex` keeps its clipped-tower behavior unchanged.

Choose the component split before drawing: the static scaffold/base contains the office, solid human, archive rails/posts and eight structural storeys, with empty contribution compartments. Each independent floor plane contains only that floor's saved artifact and localized light, with genuine alpha outside its measured cell; exclude shelf rails, posts, facade, plinth and duplicate objects already present in the base. Keep soft glow inside the floor cell rather than filling the desk or neighbouring compartments. A master already containing the contributions cannot be used under copies of those same objects; retain it as source evidence and create a separately versioned empty-content scaffold before composing content planes. Use the actual accepted scaffold as geometry reference, not a model-sheet layout. Review one native content-only floor assembled over the scaffold before authoring the remaining floors. Preserve every failed native source and composite with exact hashes and statuses; a new corrected attempt never overwrites or retroactively approves them. Repeated shelf silhouettes, translucent duplicated objects or fitted rectangles do not establish independent floor content or alignment.

Real alpha and correct content do not establish registration. Inspect the actual assembled boundaries, scale, evidence and cyan spill against the accepted master before generating more floors. A recorded scale-down/translation and explicit alpha multiplier preserve the native attempt, but cannot prove a newly drawn floor matches perspective. Cropping source bloom must retain all measured opaque/core content and record excluded alpha pixels; if evidence or essential shelf structure is cut, reject that transform. Verify the actual composited background observation and clock/reduced-motion states rather than counting intermediate alpha pixels.

Allowed presets are `still`, `push`, `drift-left`, `drift-right`, `light`, `shadow`, `projection` and isolated-light `sprout`. Beats are finite 2-8; strength and optional plane opacity are finite 0-1. No CSS or independent animation clock, repeating loop, random pulse or unimplemented effect name. The current sampler bounds push to 6% scale, drift to 1.2% horizontal travel with up to 6% scale, and light/shadow to single 10%/12% brightness pulses, multiplied by authored strength. Projection is a single small plane-opacity pulse and restrained projected edge; apply it to the authored `agents` plane, not humans, evidence or the entire page. Inspect current source if those bounds change; these numbers are not proof the movement reads well.

The existing story clock and actual responsive focus select the sample. It rests at the next focus/exit; pause and authored holds freeze it, seek/replay reproduce it, and reduced motion removes animated transforms/filters while retaining source digital styling and base opacity. Lettering, paper, frame and gutters never move. Avoid combining whole-panel `motion` and per-layer movement without a deliberate brief and actual crop check, because their transforms can compound.

All planes receive the same `ar`, inset, crop focus and phone containment transform. Check crop safety through the strongest authored sample, not only at rest. A runtime aspect/load error uses the retained `scene.art` fallback and exposes fallback/error state; require `data-art-mode="layers"` for the layered acceptance. A functioning fallback does not complete missing-plane work. Keep a real decodable fallback and verify its source hash too.

## Coverage and dwell

The layer stack is one composed page. The implemented `panel.views` contract adds separately authored reading/content/reaction cuts inside that box: each view binds an immutable source/version, unique id, panel-relative `at`, actual art region and any phone override. Freeze ordered cuts against the shared story clock and preserve balloon reading intervals and evidence holds; views do not change the scene chronology or words. The player retains hard content cuts in reduced motion. A layer stack alone does not prove ordered views, and a repeated master or crop is not a separately generated view. Keep essential evidence in the decodable `scene.art` fallback and verify actual forward/back seek, pause/hold/replay, desktop and every phone sheet after integration.

Give important source/evidence and permission/refusal beats time to be understood. Derive actual dwell from the shared retimer, responsive sheets and revealed lettering. Do not hide evidence under a balloon or cut it before its meaning lands. Existing cached speech is reusable only with exact words and matching current casting. Compare measured speech end with the next written/focus/sheet/scene window; report a conflict rather than truncate, speed up or overlap lines.

Score the whole issue through depicted ambience, event accents, silence and occasional low music. `panel.room: 'none'` and `scene.score: 0` are valid authored decisions. Reuse canonical soundtrack bytes before new generation; effects must match visible actions. Loud music requires pictured characters listening. New TTS remains blocked until the shared human exact-text/source/selected-voice approval succeeds. Stock previews and generated art acceptance cannot satisfy that gate.

## Observed layer-production escape cases

Native output dimensions and geometry are facts to measure after return, not promises in the prompt. Home's latter-four sources included a 1585px background and1586px foreground; the shared compositor rejected the unregistered mismatch before writes. An explicit guarded whole-canvas one-pixel registration resolved it. Other pages drifted from authored panel fractions and were registered region by region without redrawing source pixels. Record actual source/target rectangles, contain/cover choice, anchor, source/upscale/helper/Sharp hashes and ordered plane output hashes. Never treat enlargement as new drawn detail.

Align a source crop's intentional edge with the target frame. Centre containment left cut-off lobby torsos floating above their bases; bottom anchoring fixed the actual composition. A cropped roof closeup needed an aspect-matched source region so the cut hair/torso reached the frame, rather than a detached strip. Inspect the final composite after each registration change; matching pixel counts alone cannot detect floating bodies or stray source-gutter lines.

Physical orientation needs actual line-of-sight reasoning. Monday's first laptop foreground had a plain rear lid but still faced Marco instead of the intended Codex. The focused correction changed hinge/base direction so the screen faced Codex at right; the assembled view was inspected. Nine's source was corrected from a reversed paper presentation to an operator perspective; its first total graph also contradicted the higher quote with a longer old bar. Bind visible evidence to the story's actual consequence. No UI belongs on backs, lids or edges, and readable evidence/human/interactive-prop planes stay still while restrained background motion runs.

A lattice can be requested as architecture and still return a humanoid or rendered glass office tower. Retain either as failed; use a distinct architectural light plane in the inked cartoon style, separate from the physical city and solid humans. Home retained both actual failures and a focused ink/flat-print correction. Projection addresses accepted digital actor bodies only. An actor plane that also carries paper/evidence must remain still unless that evidence is genuinely separated; do not animate or blur the whole plane to conceal an authoring limitation.

A native transparent-background request can return genuine RGBA while its visible agent interiors are nearly opaque. Count-of-intermediate-alpha alone cannot prove projection translucency: retain the native alpha distribution (including 240–254 and 255 buckets) and inspect the actual assembled background through the agents. The fixed-coordinate composer accepts explicit plane `opacity` (default 1, finite 0–1); after alignment it multiplies only alpha, preserving decoded RGB. Its receipt separates native/aligned alpha, applied opacity and transformed output hash. The original native file remains untouched; an authored opacity transform is not a claim that the provider drew lower native alpha. Default/explicit 1 with no regions preserves exact native bytes. Actual returned human planes may also be recentered/enlarged despite prompt promises: register exact source/target rectangles and anchors, retain any failed attempts and inspect the composite. Under the current Home no-upscale plan, only scale-down/translation is allowed; the composer records enlargement instead of inventing a general policy. Apply opacity once in assembly or runtime and bind that choice in the reader data to avoid double multiplication. Neither the synthetic alpha fixture nor a transform receipt supplies D4 visual acceptance.

Raw returned sources remain immutable ingredients until registered. Review every returned file and every final plane/composite with the same `comic-visual-v1` contract, including all scene boxes and actual humans/agents/surfaces, retaining false/missing checks and unresolved findings rather than promoting source-only geometry. The four latter Home master checks bind to exact source bytes at inspection; once the integrating writer changes story/layer URLs, rebind the expected brief and review to current executing source after confirming unchanged words/action/layout and actual master bytes. Historical master evidence never automatically becomes final native acceptance. Use actual desktop/every phone sheet with final balloons, strongest motion sample and pause/seek/reduced-motion checks, plus listening, for the production receipt.
