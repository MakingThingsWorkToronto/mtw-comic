# Comic resources

## image

Read the comic-story art pipeline and imagegen skills. Reuse matching cast and scene art first. Save every attempt under wiki/image-library/assets/, run the destination checker, and register with node apps/mtw/cli/mtw.mjs register image <path...>. Review the actual composition in the reader and /m/images. Registration does not approve it.

## track

Use the local mtw-soundtrack skill and soundtrack-intake procedure. Keep source credits and licences, save audio under wiki/soundtrack-library/assets/, then run its soundtrack.mjs build and check producers. Review in /m/soundtrack. New paid requests require the current human authorization.

## character

Read wiki/site/comic-story-world.md, wiki/comics-library/characters.json and the comic-story character craft. Preserve existing likenesses. Save model sheets under wiki/image-library/assets/ and register every attempt; then update only the requested character entry in characters.json. Review at /m/comics/cast. New paid speech requires separate exact-word and voice authorization.
